ZUI

基于 Direct2D 的 C++ 原生 Win32 自绘 UI 框架，含布局、控件、信号槽与高 DPI 适配。 A native Win32 UI framework for C++, rendered with Direct2D — layouts, widgets, signals/slots, high-DPI, animations, IME and a flat design.
